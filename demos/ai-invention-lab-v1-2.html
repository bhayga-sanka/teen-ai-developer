🚀 Publish Your Invention

Ask Gemini to provide a downloadable index.html file, then publish the app using GitHub Pages.

  1. Generate: Paste the prompt into Gemini and ask for a downloadable index.html file.
  2. Save: Download the index.html attachment from Gemini. If Gemini cannot attach a file, copy the complete code and save it as index.html.
  3. Test: Browser එකේ App එක Open කරලා Buttons සහ Features වැඩ කරනවාද බලන්න.
  4. GitHub: GitHub Account එකක අලුත් Public Repository එකක් හදාගෙන index.html Upload කරන්න.
  5. Pages: Repository Settings → Pages → Deploy from a branch → Main / root තෝරා Save කරන්න.
  6. Share: Pages Link එක Open කරලා Friends / Teacher එක්ක Share කරන්න.

GitHub Account එකක් සාදන්න පෙර වයස් සීමා සහ දෙමාපිය අනුමැතිය පිළිබඳ නීති බලන්න. ඔබේ පුද්ගලික දත්ත Public Repository එකට Upload නොකරන්න.
